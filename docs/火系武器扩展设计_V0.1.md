# 火系武器扩展设计 V0.1

本文档是《游戏功能设计文档 V0.1》第 6 章（火球）与第 10 章（元素扩展）的火系内扩展：在保持"火系魔法特效测试"主题不变的前提下，新增六种攻击规则（编号 W01~W06），覆盖六种不同的视觉语法。不改动 A01~A16 已有验收用例；新增用例沿用 headless 断言风格，编号 W 系列。

## 1 设计原则（继承与新增）

1. **规则与视觉严格分离**：每把武器 = 一个 Rule 资源（纯数值，`balance/w_*.tres`）+ 两套 VfxProfile（A/B 起始建议，`balance/vfx_w_*_{a,b}.tres`）。视觉变化不产生伤害，范围伤害必须作为规则显式设计（设计文档 6.3 的既定结论，W05 是它的首次兑现）。
2. **伤害单一入口**：全部走 `DamageResolver.apply_damage`，复用 attack_id 去重、死亡唯一处理与全部命中反馈管线。
3. **发射/部署时快照**：弹体与已部署区域在生成时快照规则，升级不影响存量（开发方案 3.5）。环绕与引燃两把"持续型"武器无快照概念，规则变化即时生效，重开时从基础规则重建。
4. **击杀节奏可读**：初始敌 30 HP，火球 20 伤害两发击杀是观察反馈的基准。新武器数值均按"命中次数可数"选取（见 §9 平衡锚点）。
5. **诚实范围**：可见的预警圈、波面、区域边缘必须等于判定范围。灰度与碰撞半径显示工具继续作为验收手段。
6. **封闭竞技场条款**：所有生成点钳制到 `Arena.arena_inner_rect()` 内；飞行弹体撞墙消散沿用现行规则。

## 2 武器总览

| 编号 | 名称 | 攻击形状 | 优先级 | 试验价值（练什么视觉语法） |
| --- | --- | --- | --- | --- |
| W01 | 扇形散射火球 | 多弹体扇形 | P1（已实现） | 同屏多发时的遮挡控制与细节节流（10.4 条款的直接实验场） |
| W02 | 护体火轮 | 环绕持续体 | P1 | 循环运动的弧形尾迹、轨道提示的可读性 |
| W03 | 爆燃新星 | 环形扩散波 | P1 | 膨胀波面、击退与视觉的配合；扫掠环带几何的首实现 |
| W04 | 烈焰火池 | 地面持续区域 | P2 | 区域边缘可读性、熄灭余烬的衰减 |
| W05 | 陨星 | 延迟落点 AoE | P2 | 预警→爆点的时序反馈、范围伤害的诚实显示 |
| W06 | 引燃 | 状态附着层 | P2 | 目标身上的持续燃烧、多目标同燃的辨识与节流 |
| W07 | 火蛋 | 慢速投掷 + 落点火池 | P1（已实现） | 慢速弹体的投掷感、命中→持续区域的时序反馈；W04 的投掷递送版 |

W01~W03 形状差异最大且实现递进便宜：W01 完全复用 Fireball；W03 首次落地扫掠环带判定，该几何正是开发方案 4.3（M3 水波）所需——做火系主题的同时为水波铺路。

各武器均以 `ElementKind.FIRE` 挂入现有元素通道；试验面板与音效按武器 + 元素分流（见 §8）。

## 3 W01 扇形散射火球

### 3.1 定位

中近程面杀伤。一次开火沿基准方向扇形展开三发小火球，贴脸时全中，远距自然分散。

### 3.2 规则参数

| 参数 | 建议初始值 | 说明 |
| --- | --- | --- |
| 发射间隔 | 1.4 s | 比单发火球慢，补偿多发 |
| 每发数量 | 3 | 专属强化可增至 5 |
| 扇形总角 | 24° | 中间一发正对基准方向，两侧对称 ±12°；数量增加时等分总角 |
| 单发伤害 | 12 | 单发不杀初始敌（30 HP 需三发），近距齐中可秒杀 |
| 飞行速度 / 寿命 / 碰撞半径 / 穿透 | 480 / 2.0 s / 8 px / 0 | 与火球一致 |
| 瞄准范围 | 900 px | 同火球最近敌规则 |

### 3.3 判定条款

1. 间隔到达时按火球规则取最近存活敌的方位为基准方向；无目标不发射，进入下一次正常间隔。
2. 同一帧一次性生成全部弹体，各自独立飞行、独立扫掠检测、独立撞墙消散与到期消散；共享同一个开火事件（发射闪光一次，不重复 N 次）。
3. 每发命中即结算伤害并销毁，多发命中同一敌人各自有效。
4. 弹体发射时快照规则；数量强化只影响之后的开火。

### 3.4 视觉 A/B 起始建议

| 视觉环节 | A 版 | B 版 |
| --- | --- | --- |
| 主体半径 | 8 px（略小于火球） | 8 px，保留翻卷 |
| 尾迹寿命 | 0.08 s（短，防三发互糊） | 0.12 s |
| 命中闪光 | 0.14 s，最大 20 px | 0.18 s，最大 22 px，余烬减半 |

观察要点：三发连射时中弹提示是否被尾迹淹没；B 版是否需要按同屏弹数自动减细节（10.4 节流条款的验证）。

## 4 W02 护体火轮

### 4.1 定位

贴身防御。常驻若干火球绕玩家匀速公转，接触敌人造成伤害，弥补火球远程点杀的近身空窗。

### 4.2 规则参数

| 参数 | 建议初始值 | 说明 |
| --- | --- | --- |
| 火球数量 | 2 | 专属强化上限 6 |
| 轨道半径 | 56 px | 略大于玩家碰撞体 |
| 角速度 | 180°/s | 一圈 2 s，逆时针 |
| 单次命中伤害 | 8 | 四次转死初始敌 |
| 碰撞半径 | 10 px | 与可见主体一致 |
| 同目标再命中间隔 | 0.5 s | 按（敌人, 火球）对独立计冷却 |

### 4.3 判定条款

1. 火轮为持续型武器：不属飞行弹体，不与墙做消散判定；贴墙时轨道可视觉越出墙外（全场可见的固定场地内，墙外无敌人，不影响判定公平）。贴墙表现列为 B 版观察项。
2. 每帧按扫掠弧段检测：本帧火球扫过的弧与敌人的圆求交，防高转速穿透（与弹体扫掠同思路）。
3. 每个敌人对每颗火球 0.5 s 内只结算一次；不同火球各自独立。
4. 数量强化即时生效：新球插入并均匀重排相位（半秒内平滑过渡，禁止瞬移）；伤害、转速即时生效。回合重开从基础规则重建。
5. 玩家死亡或回合结束时整组销毁。

### 4.4 视觉 A/B 起始建议

| 视觉环节 | A 版 | B 版 |
| --- | --- | --- |
| 轨道提示 | 无 | 半透明淡虚线圆 |
| 主体 | 10 px 实心火球 | 同尺寸 + 轮廓翻卷 |
| 尾迹 | 沿圆弧的短渐隐弧段 | 更长的弧形尾迹 |

观察要点：无轨道线时玩家能否理解攻击范围（诚实范围条款）；弧形尾迹与直线尾迹的运动暗示差异。

## 5 W03 爆燃新星

### 5.1 定位

全向清围。以玩家为中心膨胀的火圈，扫到的敌人受伤并被推开，是"被围时的呼吸权"。

### 5.2 规则参数

| 参数 | 建议初始值 | 说明 |
| --- | --- | --- |
| 释放间隔 | 3.0 s | 自动释放，无需目标存在 |
| 波面到达半径 | 160 px | 专属强化按 +25% 递增，上限 240 px |
| 膨胀时长 | 0.45 s | 半径 0 → 160 匀速 |
| 伤害 | 15 | 两波击杀初始敌，与火球同为两段反馈 |
| 击退距离 | 40 px | 沿远离中心方向一次性位移；比水波(30)更猛，区分元素性格 |

### 5.3 判定条款

1. 判定采用扫掠环带：本帧波面从 r_prev 推进到 r_now，敌人中心距玩家 d 满足 r_prev < d ≤ r_now 即首次命中（几何与开发方案 4.3 水波共用）。
2. 同一次新星每敌人只命中一次；敌人事后走进已扫过的内部区域不补发伤害。
3. 击退为即时位移，落点钳制到场地内矩形，不穿墙、不把敌人推进墙。
4. 波面视觉结束后可保留 0.25 s 消散，消散不造成伤害。

### 5.4 视觉 A/B 起始建议

| 视觉环节 | A 版 | B 版 |
| --- | --- | --- |
| 波面 | 单圈清晰轮廓，膨胀速度与判定严格同步 | 双圈 + 外缘火花脱落 |
| 命中反馈 | 通用命中闪光 | 命中处向外的小火星 |
| 消散 | 0.15 s 变淡 | 0.25 s，余烬残留 |

观察要点：波面推进是否可读（玩家能否判断"还没扫到我/已扫过"）；击退与视觉冲击是否同时发生（重要反馈同时性条款）。

## 6 W04 烈焰火池（P2）

### 6.1 定位

区域封锁。周期性在玩家脚下留下一片燃烧地面；敌人追击玩家必经之路，形成"身后的火带"。

### 6.2 规则参数

| 参数 | 建议初始值 | 说明 |
| --- | --- | --- |
| 生成间隔 | 2.5 s | 每次在玩家当前位置生成 |
| 区域半径 | 40 px | 生成时快照位置，不跟随玩家 |
| 持续时间 | 3.0 s | 专属强化 +1 s，上限 6 s |
| tick 间隔 | 0.5 s | 区域内敌人每次采样受 5 伤害 |
| 同屏上限 | 12 片 | 超出时最旧片提前熄灭（防对象积累） |

### 6.3 判定条款

1. tick 按时刻采样：tick 时刻敌人中心距区域中心 ≤ 半径 + 敌半径则受伤；不记忆出入，敌人反复进出按所在时刻结算。
2. 单片总伤 30（6 tick × 5），恰好烧死一个初始敌，击杀节奏可数。
3. 生成点为玩家位置，天然在场内；到期熄灭播放余烬消散，无伤害。
4. 多片重叠时对同一敌人的 tick 各自独立结算（重叠是走位的奖励，允许）。

### 6.4 视觉 A/B 起始建议

A 版：边缘清晰的暗红火圈 + 低矮火苗；B 版：边缘不规则舔动、亮度随剩余寿命衰减、熄灭时焦痕淡出 0.4 s。观察要点：区域边缘在灰度下的可辨认性（沿用 A16 人工观察流程）；多片连成火带时的整体噪音水平。

## 7 W05 陨星（P2）

### 7.1 定位

定点爆发。预警后一颗陨星砸落，圈内一发击杀初始敌——设计文档 6.3 预留的"范围伤害作为新攻击规则另行设计"的首次兑现。

### 7.2 规则参数

| 参数 | 建议初始值 | 说明 |
| --- | --- | --- |
| 落点间隔 | 3.5 s | 专属强化数量 +1，上限同刻 3 颗 |
| 目标选取 | 900 px 内随机存活敌人当前位置 | 用 Rng（种子可控，headless 可测）；无目标不落，进入下一次间隔 |
| 预警时长 | 0.8 s | 地面渐强红圈 |
| 爆炸半径 | 70 px | 预警圈半径 = 爆炸半径（诚实范围） |
| 伤害 | 35 | 圈内一发击杀初始敌（溢出 5 表达爆发感） |

### 7.3 判定条款

1. 落点时刻即时采样：预警结束时，以落点为中心半径内所有存活敌人均受一次伤害——预警期内走进圈的敌人也受击，走出圈的不受击。预警圈即真实伤害圈，不做入场快照。
2. 落点钳制到场地内矩形。
3. 每颗陨星对每敌人只结算一次；多颗陨星各自独立。

### 7.4 视觉 A/B 起始建议

A 版：红圈预警 + 快速下坠体（0.15 s 斜落）+ 落地爆闪；B 版：预警圈内地面裂纹预示、坠落拖焰尾、落地冲击环 + 焦痕残留 0.4 s 淡出（无伤害）。观察要点：0.8 s 预警的"期待感"是否成立；爆闪是否过强掩盖后续弹体（10.4 闪白条款）。

## 8 W06 引燃（P2，附魔层）

### 8.1 定位

不是独立武器，而是可开关的附魔：所有火系武器的有效命中附加引燃状态。它同时是后续"元素状态效果"框架（灼烧/感电/潮湿）的样板。

### 8.2 规则参数

| 参数 | 建议初始值 | 说明 |
| --- | --- | --- |
| 持续时间 | 3.0 s | 再次命中只刷新剩余时长，不叠加层数 |
| tick 间隔 | 0.5 s | 从首次点燃起独立连续计时，总伤 18 |
| 开关 | 试验面板/平衡配置 | 首版默认关闭，作为观察项不平衡数值 |

### 8.3 判定条款

1. tick 计时不因再次命中而重置：持续命中只延长尾巴，不拖延已有跳数（点燃直觉：烧着就是烧着）。
2. 引燃伤害走 DamageResolver，element 记 FIRE；击杀归属触发引燃的那次攻击。
3. 敌人死亡时引燃随死亡流程一并清除，不残留视觉。

### 8.4 视觉与观察

敌人轮廓边缘的小火苗（三角形抖动）+ 每 tick 微闪光，濒死熄灭。观察要点：十几个敌人同燃时的辨识与性能（同刻 tick 需做闪光错峰）；火苗是否被敌人本体色淹没（灰度验收）。

## 8A W07 火蛋（已实现，随 W01 同批）

### 8A.1 定位

慢速投掷物：朝最近敌人扔出一颗火蛋，飞得慢、目标大，终点（命中敌人/撞墙/到期）生成一片燃烧区域。火蛋本体不直接造成伤害——燃烧区域才是伤害来源，"范围伤害是显式规则而非视觉"（W04 的投掷递送版）。

### 8A.2 规则参数（balance/fire_egg_rule.tres）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 投掷间隔 | 2.5 s | 自动瞄准最近敌，无目标不投 |
| 飞行速度 | 160 px/s | 约火球 1/3，慢速可读的投掷感 |
| 最长存活 | 3.0 s | 到期原地烧尽 |
| 蛋体碰撞半径 | 10 px | 大目标：慢而不易落空 |
| 火池半径 | 40 px | 池圈即伤害圈（诚实范围） |
| 火池持续 | 3.0 s | 末端 0.4 s 淡出，消散无伤害 |
| 火池 tick | 0.5 s × 5 伤 | 6 跳总伤 30，恰好烧死一个初始敌 |
| 同屏火池上限 | 12 片 | 超出时最旧一片提前熄灭 |

### 8A.3 判定条款

1. 终点统一生成火池：命中敌人（扫掠检测停在命中点）、撞墙、到期三者等价，火蛋本身不结算伤害。
2. 池心钳制使整池收进内区矩形（诚实范围：伤害圈不藏进墙里）。
3. 火池每跳用新的 attack_id 采样：同一敌人可被逐跳反复灼烧，每跳至多一次。
4. 火池生成时快照规则；升级不影响已落地的火池。

### 8A.4 视觉起始（单版，无 A/B）

蛋体沿飞行方向拉长的椭圆 + 轻微呼吸脉动 + 短尾迹；火池为内淡外亮的灼烧圈 + 环上 8 处独立呼吸的火苗 + tick 结算瞬间的提亮环（伤害与视觉同时发生）。

## 9 平衡锚点

以火球 20 DPS 单体为基线，新武器按定位分散：

| 武器 | 单体期望 DPS | 定位 |
| --- | --- | --- |
| 火球（基线） | 20 | 远程点杀 |
| W01 散射 | 10 ~ 26 | 中近程面杀（远距分散，贴脸全中） |
| W02 火轮 | 8 ~ 16 | 贴身防御（站桩上限） |
| W03 新星 | 5 | 全向清围 + 击退 |
| W04 火池 | 10 / 片 | 区域封锁（敌人路径重叠时叠加） |
| W05 陨星 | ≈ 10 | 定点爆发 |
| W06 引燃 | +18 后置 | 附魔增伤 |

数值只用于首轮比较；每把武器接入时在 `balance/` 建独立 .tres，调平衡不动代码。

## 10 升级系统接线

- 现有 FIRE_DAMAGE / FIRE_INTERVAL 推广为火焰伤害 / 火焰频率：作用于全部 FIRE 武器各自的 damage / 间隔字段（散射按单发、陨星按每颗等比），文案改"火焰伤害"。
- 每把新武器至多一条专属强化，进入现有三选一池：散射数量（3→5）、火轮数量（2→6）、新星半径（+25%，上限 240）、火池持续（+1 s，上限 6）、陨星数量（1→3）。引燃无强化条目。
- 三选一、不重复、满级回血框架不动。

## 11 系统实现映射

| 事项 | 方案 |
| --- | --- |
| 枚举 | `GameEnums.WeaponKind { FIREBALL, SCATTER, ORBIT, NOVA, GROUND_FIRE, METEOR }`；ElementKind 不变 |
| 控制器 | 每武器一个 systems/ 控制器（对齐 projectile_manager 的 tick 驱动模式；开发方案已预留 chain/wave_controller 同款） |
